# Which constants matter: a sensitivity sweep

Generated by `node scripts/sweep_constants.js` (4,000 futures per run, default assumptions, common random numbers). Do not edit by hand.

Every named constant in `model.js` (the `K` object, 169 constants) was moved low and high while all others stayed at their defaults. Scale constants (rates, weights, widths) run at ×0.5 and ×1.5. Midpoints, thresholds and starting levels on the 0–100 scale run at ±10 points; the deal's diplomacy threshold and the onset gate's midpoint (a 0–1 share) run at ±0.1. Each run reports the change, in percentage points, of seven headline numbers: catastrophe under Status quo, Plan A and the Safest mix, and p(alignment) under AI 2040's Plans A–D. The bio hazard scale is recalibrated in every run, as in the model itself, so bio constants change pandemic risk only off the default path.

Baseline (default constants, this sampling): Status quo catastrophe 82.1%, Plan A catastrophe 19.2%, Safest mix catastrophe 1.4%, Plan A p(alignment) 76.6%, Plan B p(alignment) 45.3%, Plan C p(alignment) 39.9%, Plan D p(alignment) 16.8%.

By class: source 8, fitted 7, baseline offset 17, judgment 137. Classes: **source** = taken from a cited forecast (mostly AI 2040); **fitted** = tuned so the model hits a calibration target (Plans A–C p(alignment), the AI 2040 timeline, the lock-in share); **baseline offset** = a 2027 starting level or a drift term that sets the status-quo trend; **judgment** = an illustrative modelling choice.

Fitted constants are not free: moving one moves the calibration target it was fitted to (for example the AI 2040 timeline or Plans A–C p(alignment)), so their swings show how much that target matters rather than an independent uncertainty. Each row moves one constant at a time; interactions between constants are not explored.
